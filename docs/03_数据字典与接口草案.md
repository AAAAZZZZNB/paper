# 数据字典与接口草案

## 1. 统一标识和版本字段

所有核心对象建议包含：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 全局唯一标识 |
| `source_id` | string | 原始来源标识 |
| `version` | string | 对象版本 |
| `status` | enum | draft/reviewed/published/retired |
| `created_at` | datetime | 创建时间 |
| `updated_at` | datetime | 更新时间 |
| `created_by` | string | 创建人 |
| `evidence_refs` | array | 证据引用列表 |

## 2. 事故数据 AccidentRecord

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `accident_id` | string | 是 | 事故编号 |
| `occurred_at` | datetime | 是 | 发生时间 |
| `road_id` | string | 是 | 道路/路段编号 |
| `direction` | string | 否 | 行驶方向 |
| `milepost` | string/number | 否 | 里程位置 |
| `road_scene` | string | 否 | 主线、匝道、长下坡、弯道等 |
| `weather` | string | 否 | 天气条件 |
| `visibility` | number | 否 | 能见度 |
| `vehicle_types` | array | 否 | 车辆类型 |
| `accident_type` | string | 是 | 事故类型 |
| `severity_label` | string | 是 | 严重程度标签 |
| `casualties` | object | 否 | 伤亡字段 |
| `property_loss` | number | 否 | 路产或财产损失 |
| `description` | text | 否 | 脱敏描述 |
| `asset_refs` | array | 否 | 图片/文档资产引用 |

## 3. 轨迹点 TrajectoryFrame

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `track_id` | string | 是 | 轨迹批次 |
| `vehicle_id` | string | 是 | 脱敏车辆 ID |
| `timestamp` | datetime | 是 | 时间戳 |
| `x` / `y` | number | 是 | 坐标 |
| `lane_id` | string | 否 | 车道 |
| `speed` | number | 是 | 速度 |
| `acceleration` | number | 否 | 加速度 |
| `heading` | number | 否 | 航向 |
| `vehicle_type` | string | 否 | 车辆类型 |
| `quality_flag` | string | 是 | 原始/插值/异常修复等 |

## 4. 冲突事件 ConflictEvent

| 字段 | 类型 | 说明 |
|---|---|---|
| `conflict_id` | string | 冲突编号 |
| `track_id` | string | 所属轨迹批次 |
| `vehicle_a` / `vehicle_b` | string | 交互车辆 |
| `occurred_at` | datetime | 冲突时间 |
| `road_id` | string | 道路/路段 |
| `tdtc` | number | 车辆间 TDTC |
| `mttc` | number | MTTC |
| `pet` | number | PET |
| `delta_v` | number | 速度差 |
| `threshold_version` | string | 判定阈值版本 |
| `risk_level` | string | 规则判定等级 |
| `rule_reasons` | array | 触发规则 |

## 5. SHAP 解释结果 ShapResult

| 字段 | 类型 | 说明 |
|---|---|---|
| `task_id` | string | 分析任务编号 |
| `dataset_version` | string | 数据版本 |
| `model_version` | string | 模型版本 |
| `feature` | string | 特征名 |
| `target` | string | 目标变量 |
| `mean_abs_shap` | number | 平均绝对 SHAP |
| `direction` | string | 正向/负向/非单调 |
| `group_scope` | object | 分组范围 |
| `sample_count` | integer | 样本数 |
| `plot_refs` | array | 图表资产 |
| `knowledge_candidate` | boolean | 是否可形成知识候选 |

## 6. EVT 结果 EvtResult

| 字段 | 类型 | 说明 |
|---|---|---|
| `task_id` | string | 分析任务编号 |
| `indicator` | string | TDTC/MTTC/PET/ΔV |
| `threshold` | number | POT 阈值 |
| `model_type` | string | GPD/GEV |
| `parameters` | object | 模型参数 |
| `confidence_interval` | object | 置信区间 |
| `return_level` | object | 重现水平 |
| `covariates` | array | 非平稳协变量 |
| `stability_score` | number | 稳定性评分 |
| `published_rule_id` | string | 发布后的规则编号 |

## 7. 事件 Incident

| 字段 | 类型 | 说明 |
|---|---|---|
| `incident_id` | string | 事件编号 |
| `source_type` | string | manual/accident/conflict/stream |
| `road_id` | string | 道路/路段 |
| `event_time` | datetime | 事件时间 |
| `raw_description` | text | 原始描述 |
| `parsed_entities` | array | 解析实体 |
| `rule_risk_level` | string | 规则最低等级 |
| `final_risk_level` | string | 最终等级 |
| `status` | string | 事件状态 |
| `assignee` | string | 责任人/班组 |
| `evidence_pack_id` | string | 证据包编号 |
| `report_id` | string | 报告草案编号 |

## 8. 知识条目 KnowledgeEntry

```json
{
  "knowledge_id": "KN-ACC-0001",
  "type": "accident_knowledge",
  "subject": "夜间",
  "predicate": "increases_risk",
  "object": "事故严重程度",
  "value": 0.312,
  "unit": "mean_abs_shap",
  "scope": {"road_type": "高速公路"},
  "source": {"dataset": "ACC-2026-01", "model": "xgb-v0.3"},
  "status": "reviewed",
  "evidence_refs": ["SHAP-TASK-0001"]
}
```

## 9. 风险评估报告 ReportDraft

报告至少包含：

- `summary`
- `risk_level`
- `risk_index_or_range`
- `risk_causes`
- `key_factors`
- `threshold_results`
- `graph_evidence`
- `similar_cases`
- `recommendations`
- `unknown_or_to_verify`
- `evidence_refs`
- `review_status`
- `llm_model_version`
- `prompt_version`
- `validation_results`

## 10. 接口返回约定

所有接口建议返回：

```json
{
  "request_id": "REQ-2026-0001",
  "success": true,
  "data": {},
  "warnings": [],
  "errors": [],
  "trace": {
    "dataset_version": null,
    "model_version": null,
    "knowledge_version": null,
    "rule_version": null
  }
}
```

错误必须区分：参数错误、数据质量错误、模型运行错误、知识检索为空、权限错误、LLM 超时和人工审核阻断。
